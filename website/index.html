常見問題

初次使用 Zero Launcher？這裡有你需要的解答。

Q: 執行 Zero Launcher 需要另外安裝 Java 嗎？

Zero Launcher.exe 會自動智慧搜尋您電腦現有的 Java 環境。若完全未安裝，啟動器會貼心引導您一鍵下載推薦的 Eclipse Adoptium Java 21。

Q: 我原本的 Minecraft 存檔與模組會遺失嗎？

完全不會。Zero Launcher 具備完善的向下相容遷移機制，會無縫繼承並保護您所有現存的遊戲實例、存檔、模組與設定檔。

Q: 為什麼點擊按鈕沒有水波紋了？

這是 Zero Launcher 的特色之一！我們全面移除了 Android 手機 App 風格的延遲水波紋，改用桌面端自研的即時物理下壓與彈簧回彈手感，反應更加敏捷！
